# Nordic Burgundy Color Reference

## Primary Brand Color

### Nordic Burgundy
```
Hex: #5A2633
RGB: rgb(90, 38, 51)
HSL: hsl(346, 41%, 25%)
```

**Usage:**
- Hero sections
- Primary buttons
- Brand highlights
- CTA backgrounds
- Navigation active states

### Nordic Burgundy Dark (Hover State)
```
Hex: #4a1f29
RGB: rgb(74, 31, 41)
HSL: hsl(346, 41%, 21%)
```

**Usage:**
- Button hover states
- Interactive elements on hover
- Focus states

## Color Psychology

**Nordic Burgundy** conveys:
- 🎓 **Professionalism** - Perfect for education
- 💼 **Authority** - Establishes credibility
- 🏛️ **Heritage** - Traditional and established
- ⚖️ **Sophistication** - Refined and elegant

## Accessibility

### Contrast Ratios (with white text)
- Nordic Burgundy (#5A2633): **9.2:1** ✅ WCAG AAA
- Nordic Burgundy Dark (#4a1f29): **11.5:1** ✅ WCAG AAA

Both colors meet WCAG AAA standards for text contrast!

## Usage Examples

### Gradients
```css
/* Hero gradient */
background: linear-gradient(135deg, #5A2633, #410000);

/* Button gradient */
background: linear-gradient(to bottom right, #5A2633, #5A2633);
```

### Tailwind Classes
```html
<!-- Background -->
<div class="bg-[#5A2633]">

<!-- Text -->
<span class="text-[#5A2633]">

<!-- Border -->
<div class="border-[#5A2633]">

<!-- Hover -->
<button class="bg-[#5A2633] hover:bg-[#4a1f29]">
```

### CSS Variables (if needed later)
```css
:root {
  --nordic-burgundy: #5A2633;
  --nordic-burgundy-dark: #4a1f29;
  --nordic-burgundy-light: #6b2d3d;
}
```
